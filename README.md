# Social Network

Учебное приложение социальной сети на React и Vite.

## Возможности

- Лента общих публикаций и профиль с созданием и удалением записей.
- Сохранение публикаций в `localStorage`.
- Счётчики лайков и репостов для каждой записи.
- Три темы оформления и отдельные страницы «Настройки» и «О проекте».

## Запуск

```sh
npm install
npm run dev
```

Для проверки production-сборки используйте `npm run build`, для проверки стиля кода — `npm run lint`.
